## What is Swipey?

Swipey is a Tinder-style content-idea app for creators. You swipe through a deck of AI-generated idea cards scoped to your niche — **Tech Reviews**, **Gaming**, or **Fashion** — like the ones you want, generate full scripts with Gemini, and push them straight to Notion.

The interaction model is the product: every screen is designed around the swipe loop.

```
Onboard (pick niche)  →  Swipe deck  →  Like / Save / Dismiss
        ↓                                       ↓
  Niche-scoped ideas          Expanded Echo — generate full script
                                      ↓
                              Send to Notion database
```

## Features

### Core Swipe Loop
- **Tinder-style card stack** — swipe left to dismiss, right to like (opens Echo), up to save
- **Niche-filtered deck** — select Tech, Gaming, or Fashion during onboarding and receive only ideas from that niche
- **30 curated seed ideas** — 10 per niche, immediately available with no API key needed

### AI Generation
- **Expanded Echo** — tap "Generate Content" on any liked idea to get a full creator script, post, or guide generated by Gemini 3.1 Flash Lite
- **Typewriter reveal** — content types out character by character for a satisfying reveal
- **Grounded device facts** — when a device (e.g. iQOO 15) appears in tech ideas, the AI uses only verified official specs — no hallucinated benchmarks

### Notion Integration
- **Send to Notion** — push any idea directly to your Notion database from the Expanded Echo screen
- **Bulk export** — export all saved ideas at once from Settings → Notion
- Each Notion page includes: title, niche, category, tags, and the full generated script

### Onboarding
- **3-step onboarding** — pick your niche (Tech / Gaming / Fashion), sub-topics, and posting goal
- **Persona names** — your greeting adapts: "Good morning, Gamer" / "Good afternoon, Techie" / "Good evening, Fashionista"
- **Defaults pre-selected** — tap through in under 10 seconds for a demo

### Dashboard
- **Loved Ideas list** — all your saved ideas in one place, each tappable into Expanded Echo
- **Daily target tracker** — progress bar toward your goal (10 ideas for Pro)
- **Streak counter** — tracks how many ideas you've saved

### Settings & Profile
- **Profile screen** — shows your niche, goal, and saved count
- **Settings** — push notifications, daily reminder, reduced motion, Notion + Calendar toggles (persisted to the backend)

### Technical
- **Offline-first** — seed ideas work with zero API key; Gemini features gracefully degrade to a 503 with a clear message
- **Deduplication** — Jaccard similarity on summary tokens prevents near-duplicate ideas being generated
- **Feedback loop** — rejected ideas extract negative markers that steer future generation prompts (RAG-lite)
- **Cleartext LAN** — dev-only network security config lets your phone reach the laptop backend over Wi-Fi

## Quick Start

### Prerequisites

- macOS (tested on macOS with zsh)
- Python 3.9+, pip
- Android Studio with SDK and an Android device or Pixel_9 emulator
- A Gemini API key (optional — seed ideas work without one)
- A Notion integration token + database ID (optional — for push-to-Notion)

### 1. Clone and set up the backend

```bash
cd backend-swipey
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Edit `.env` and add your credentials (all optional — app works without them):

```env
GEMINI_API_KEY=your_gemini_key_here
GEMINI_MODEL=gemini-3.1-flash-lite

NOTION_TOKEN=secret_your_notion_token
NOTION_DATABASE_ID=your_32char_database_id
```

### 2. Configure the Android app base URL

The emulator reaches your laptop at `10.0.2.2:8000` automatically — no change needed.

For a **physical phone** on the same Wi-Fi, find your laptop's LAN IP:
```bash
ipconfig getifaddr en0      # e.g. 192.168.1.42
```

Add one line to `local.properties` (project root):
```properties
SWIPEY_API_BASE=http://192.168.1.42:8000/
```

### 3. Run the demo reset script

This is the recommended way to start a fresh demo. It:
1. Kills any running backend on port 8000
2. Wipes and re-seeds the database (30 fresh ideas)
3. Starts the FastAPI server in the background
4. Builds and installs the debug APK on your connected device
5. Clears app data for a clean onboarding run

```bash
./demo_reset.sh
```

4. Tap **Send to Notion** → idea lands in your Notion database instantly
5. Switch to the **Dashboard** tab to see your saved ideas and progress

## Backend API

All endpoints under `/api/v1`. Interactive docs at **http://localhost:8000/docs**.

| Method | Endpoint | Description |
|---|---|---|
| GET | `/health` | Server status + Gemini/Notion enabled flags |
| GET | `/ideas/deck?niche=gaming` | Pending deck (filtered by niche) |
| GET | `/ideas/saved` | All saved/liked ideas |
| POST | `/ideas/{id}/swipe` | `{"action":"approve"\|"reject"\|"save"}` |
| POST | `/ideas/{id}/echo` | Generate full script with Gemini |
| PATCH | `/ideas/{id}/tags` | Update tags |
| POST | `/ideas/{id}/notion` | Push one idea to Notion |
| POST | `/saved/notion` | Push all saved ideas to Notion |
| POST | `/generate` | AI-generate new ideas for a niche |
| GET | `/catalog/niches` | Available niches |
| GET | `/profile` | User profile (niche, goal, settings) |
| PUT | `/profile` | Update profile |
| GET | `/profile/settings` | Get settings |
| PUT | `/profile/settings` | Update settings |

## Notes

- **Secrets:** `.env` is git-ignored. Never commit API keys. Rotate keys shared in chat immediately.
- **Notion setup:** create a Notion integration at https://www.notion.so/my-integrations, create a database, share the database with your integration, then copy the token and database ID from the URL.
- **Gemini model:** configurable via `GEMINI_MODEL` in `.env`. The installed SDK (`0.5.2`) works with `gemini-1.5-flash`, `gemini-1.5-pro`, and `gemini-3.1-flash-lite`.
- **Reinstall behaviour:** onboarding re-runs on reinstall (expected). Your saved ideas and settings persist on the backend under the `demo` user.
